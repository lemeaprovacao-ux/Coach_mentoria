# LEME — Coaching & Mentoria

O **LEME — Coaching & Mentoria** é um projeto web desenvolvido para apresentar uma proposta de preparação estratégica para concursos públicos, com foco em **planejamento, organização, disciplina, acompanhamento e evolução**.

O projeto utiliza uma identidade visual moderna, baseada nas cores **azul-marinho, dourado e ciano**, incorporando elementos visuais relacionados a direção, navegação, estratégia e tecnologia.

## 🎯 Objetivo

Criar uma plataforma institucional para apresentar a metodologia do LEME, aproximar o candidato de uma preparação estruturada e apresentar a trajetória profissional do coach.

## 🧭 Estrutura do projeto

- **Início** — apresentação da proposta e chamada principal.
- **O Método** — diagnóstico, planejamento e acompanhamento.
- **Para quem é** — diferentes perfis de candidatos.
- **Jornada** — etapas da preparação.
- **O Coach** — apresentação profissional e trajetória.
- **Contato** — canais de comunicação.
- **Perfil profissional** — acesso à página pessoal do coach.

## ✨ Recursos visuais

- Design responsivo;
- Identidade visual própria;
- Brasão e logotipo LEME;
- Fundos com efeitos tecnológicos;
